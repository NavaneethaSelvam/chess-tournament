# Chess Tournament Management System

A web-based Chess Tournament Management System built using Svelte and JavaScript.

## Features

- Player Management
- Add, edit, and delete players
- Tournament Management
- Add players to tournaments
- Random match generation
- Random winner selection
- Match result tracking
- Top 3 player rankings

## Tech Stack

- Svelte
- JavaScript
- Vite
